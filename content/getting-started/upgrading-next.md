Nothing on `main` since 0.6.5 changes how existing apps behave yet. Changes
for the next release are listed here as they land.

The changes that were on this page shipped in 0.6.0, 0.6.1, 0.6.3 and 0.6.5.
See [Upgrading to 0.6](/getting-started/upgrading-0.6).
